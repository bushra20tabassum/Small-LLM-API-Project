# Small LLM API Project

## Project Overview

This project demonstrates how to connect a Python application to a Large Language Model (LLM) using the Google Gemini API. The application sends a user's prompt to the AI model and displays the generated response.

## Technologies Used

* Python
* Google Gemini API
* Google Gen AI SDK
* Visual Studio Code

## How the Request Works

1. **User Input:** The user enters a question or prompt into the application.
2. **API Request:** The Python program sends the prompt to the Google Gemini API using the Google Gen AI SDK.
3. **AI Processing:** The Gemini model processes the prompt and generates a response.
4. **API Response:** The generated response is returned to the Python program.
5. **Display Output:** The application displays the AI-generated answer to the user.

## Request Flow

User Prompt → Python Application → Gemini API → Gemini AI Model → API Response → Application Output

## Conclusion

This project helped me understand how to integrate an LLM API into a Python application and how requests and responses are exchanged between an application and an AI model.
